# 🌟 Lumo AI

**A Smart AI-Powered Assistant Built with Python and Streamlit**

Lumo AI is a modern AI assistant designed to help users with everyday questions and tasks. It provides an easy-to-use interface with AI chat, voice features, image analysis, and chat history.

## ✨ Features

- 🤖 AI-powered chat using Groq
- 🎤 Voice input
- 🔊 Text-to-speech responses
- 🖼️ Image analysis
- 💬 Chat history
- 🌐 Multiple language support
- 🧠 Think mode
- 🎨 Modern dark-themed interface
- 🔐 Google Sign-In (when configured)

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- gTTS
- Whisper (for voice input)

## 🚀 Run Locally

1. Download or clone this repository.
2. Open the project folder in your terminal.
3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure your API key using Streamlit secrets.
5. Start the app:

   ```bash
   streamlit run app.py
   ```

## 🔑 Configuration

Add your required API keys and authentication settings through Streamlit secrets. **Never publish API keys, passwords, or private credentials on GitHub.**
